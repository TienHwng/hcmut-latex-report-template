# Template options

[Tiếng Việt](../vi/02-tuy-chon.md) | **English**

Options go on the `\usepackage` line in `main.tex`. You can combine several, separated by commas, in any order:

```latex
\usepackage{config/report}                        % default: English, final version
\usepackage[vietnamese]{config/report}            % Vietnamese, final version
\usepackage[vietnamese,draft]{config/report}      % Vietnamese, draft
\usepackage[vietnamese,print,lists]{config/report}
```

| Option | Effect |
| --- | --- |
| `english` | (default) Text generated by the template is in English |
| `vietnamese` | Text generated by the template is in Vietnamese |
| `final` | (default) Final version: no notes, no watermark |
| `draft` | Draft: shows `\todo`/`\note` notes, the list of notes and a DRAFT watermark |
| `print` | Printed copy: links and citation numbers in black instead of blue |
| `lists` | Adds a list of figures and a list of tables after the table of contents |

A misspelled option (for example `vietnam`) does **not** make the build fail. The log only shows an `Unknown option` warning and the option has no effect, so it is easy to miss.

## Language: `english` / `vietnamese`

> [!IMPORTANT]
> The language option **only changes the text the template generates**. What you write in `chapters/` stays as it is: for a Vietnamese report, you write the chapters in Vietnamese yourself.

| Where | `english` | `vietnamese` |
| --- | --- | --- |
| List headings | Contents, References, List of Figures, List of Tables, List of Abbreviations | Mục lục, Tài liệu tham khảo, Danh sách hình vẽ, Danh sách bảng, Danh mục từ viết tắt |
| Captions | Figure 1.1, Table 1.1, Listing 1 | Hình 1.1, Bảng 1.1, Đoạn mã 1 |
| `\cref{...}` | Section 2, Figure 1.1, Table 1.1, Equation (1.1), Appendix A | Mục 2, Hình 1.1, Bảng 1.1, Công thức (1.1), Phụ lục A |
| Appendices | Appendix A | Phụ lục A |
| Cover page | Instructor, Class, Group, Student's Name, Student ID | Giảng viên hướng dẫn, Lớp, Nhóm, Họ và tên, MSSV |
| Member tables | No., Full name, Contribution, Percentage, Evaluation, Signature | STT, Họ và tên, Nhiệm vụ, Mức độ, Đánh giá, Chữ ký |
| Front page headings | Member List & Workload, Lecturer's Assessment, Declaration | Danh sách thành viên & phân công, Đánh giá của giảng viên, Lời cam đoan |
| Footer | Semester 252, Page 3/10 | Học kỳ 252, Trang 3/10 |
| Default date | November 2026 | tháng 11 năm 2026 |
| Hyphenation, PDF language | English | Vietnamese |

Switching the language does **not** translate what you write yourself: the data in `config/metadata.tex` (the university, the course name, the page header, the members' tasks) and the chapter text. The placeholder chapters on `main` are in English, so turning on `vietnamese` alone gives a half-English, half-Vietnamese report until you rewrite them. For a Vietnamese report, write those parts in Vietnamese.

### Text that depends on the language

Most reports are written in one language and never need this. But if you want a paragraph to follow the option, for example to keep one source for both languages, use `\ifreportvietnamese`:

```latex
\ifreportvietnamese
  Nội dung tiếng Việt.
\else
  English content.
\fi
```

`frontmatter/declaration.tex` uses exactly this to provide the declaration in both languages.

### An English passage in a Vietnamese report

Both languages are always loaded. A long English quotation inside a Vietnamese report can use English hyphenation:

```latex
\begin{otherlanguage}{english}
  A long quotation in English ...
\end{otherlanguage}
```

## Draft: `draft`

Use it while writing and revising:

- `\todo{...}` and `\note{...}` notes appear in the margin (see [Teamwork](08-teamwork.md#notes-for-each-other)).
- A **List of Todos** page after the table of contents lists every note; click a line to jump to it.
- Every page carries a grey **DRAFT** watermark, so a draft can never be mistaken for the final version.

Remove `draft` and all three disappear. You do not need to delete the notes from the source files.

## Printed copy: `print`

By default, links, citation numbers and references are blue so they stand out on screen. On paper, blue text looks like a printing fault, so `print` turns them back to the normal text colour. Links still work when the PDF is opened.

Leave `print` **out** for an electronic submission and add it for a printed one.

## Lists of figures and tables: `lists`

Adds a *List of Figures* and a *List of Tables* right after the table of contents; both also get an entry in the table of contents. Useful when the report has many figures and tables, or when the course requires them.

The **list of abbreviations** needs no option: it appears by itself as soon as `config/abbreviations.tex` declares an abbreviation (see [Abbreviations](07-abbreviations.md)).

## Trying an option without editing main.tex

Want to look at the draft without changing the `main.tex` the whole group shares? Copy `main.tex` to `test.tex`, edit the `\usepackage` line in the copy, and build it:

```sh
latexmk test.tex
```

Afterwards, delete `test.tex`, `test.pdf` and `test.synctex.gz`.
